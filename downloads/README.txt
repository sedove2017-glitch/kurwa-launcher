Сюда кладутся готовые сборки лаунчера, чтобы кнопки «Скачать» работали
без внешнего хостинга файлов:

  KurwaLauncher-setup-0.1.0.exe   — установщик
  KurwaLauncher-0.1.0-portable.exe — portable-версия

Папку целиком можно заархивировать и отдать друзьям — сайт откроется
двойным кликом по index.html.

Для публикации в интернете большие .exe лучше держать в GitHub Releases
(до 2 ГБ на файл), а не в репозитории сайта (там лимит 100 МБ на файл).
Тогда ссылки в site/config.js указываются на ассеты релиза.
